# Formula Brasil 1

Protótipo inicial de jogo de corrida 3D em navegador, construído com Three.js e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Controles

- W ou seta para cima: acelerar
- S ou seta para baixo: frear
- A/D ou setas esquerda/direita: direcionar
- C: alternar cockpit e câmera externa
- Esc: pausar

## Estado do projeto

Esta primeira entrega estabelece a cena 3D, circuito noturno inspirado em Las Vegas, carro protótipo, cockpit, HUD e controles básicos. Próximas etapas: física veicular mais precisa, modelo 3D de carro de maior fidelidade, áudio, adversários, sistema de corrida e multiplayer com servidor autoritativo e salas de até 20 pilotos.

O multiplayer não está implementado nesta etapa inicial.
